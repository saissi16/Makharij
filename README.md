# بناء تطبيق مخارج الحروف (APK) بدون برامج

لا تحتاج إلى تثبيت أي برنامج. GitHub يبني التطبيق لك مجانًا.

## الخطوات
1. أنشئ حسابًا مجانيًا في github.com (إن لم يكن لديك).
2. اضغط (+) ثم New repository. سمّه makharij واترك الباقي كما هو، ثم Create repository.
3. اضغط "uploading an existing file" وفك ضغط هذا المجلد، ثم اسحب كل محتوياته إلى الصفحة
   (يجب أن يشمل المجلدات: www و scripts و .github والملفات: package.json و capacitor.config.json).
   ثم اضغط Commit changes.
   ملاحظة: إن لم يظهر المجلد .github بعد الرفع، اضغط Add file ثم Create new file،
   واكتب الاسم  .github/workflows/build-apk.yml  والصق فيه محتوى الملف الموجود بالمجلد.
4. افتح تبويب Actions. إن طلب منك تفعيلها فاضغط الموافقة.
   اختر Build APK ثم Run workflow. انتظر نحو 5 إلى 10 دقائق حتى تظهر علامة ✓ خضراء.
5. افتح التشغيلة المكتملة، وفي الأسفل (Artifacts) نزّل makharij-apk. هو ملف مضغوط، فك ضغطه تجد app-debug.apk.
6. انقل app-debug.apk إلى الهاتف وافتحه. إن طلب الهاتف السماح بالتثبيت من هذا المصدر فوافق.
7. عند أول ضغطة على الميكروفون اسمح للتطبيق باستخدامه.

## ملاحظات
- التعرّف على الكلام العربي يستخدم خدمة Google في الهاتف. تأكد أن تطبيق Google مثبّت ومحدّث،
  وأن اللغة العربية متاحة في إعدادات الكتابة الصوتية. قد يحتاج إلى اتصال بالإنترنت.
- التطبيق نفسه يعمل دون إنترنت، لكن الخطوط الجميلة (Amiri) تُحمَّل من الإنترنت عند توفره،
  وبدونه يستخدم الهاتف خطًا عربيًا افتراضيًا.
- هذا ملف تجريبي (debug) للاستعمال الشخصي. لنشره في متجر Google Play يلزم توقيع إصداري.
- إن فشل البناء، افتح التشغيلة الفاشلة وانسخ نص الخطأ وأرسله لي لأصلحه.
